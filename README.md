# Entwicklung eines Antriebsstrangs für eine Brikettieranlage

## Überblick

Diese Projektarbeit wurde im Rahmen des Maschinenbaustudiums durchgeführt.

Ziel war die Entwicklung und Auslegung eines vollständigen Antriebsstrangs für eine industrielle Brikettieranlage mit zwei gegenläufig angetriebenen Walzen.

Der Antriebsstrang umfasst einen Elektromotor, ein Vorschaltgetriebe, ein Sonderstirnradgetriebe mit zwei synchronisierten Abtriebswellen sowie alle relevanten Maschinenelemente.

## Projektrahmen

- Bearbeitungszeitraum: 10/2023 – 01/2024
- Studiengang: Maschinenbau
- Projektart: Projektarbeit

## Aufgabenstellung

- Auswahl des Elektromotors
- Auswahl eines Vorschaltgetriebes
- Entwicklung eines Sonderstirnradgetriebes
- Berechnung von Drehzahlen und Drehmomenten
- Auslegung der Wellen
- Auswahl und Berechnung der Wälzlager
- Auslegung der Kupplungen
- Wirkungsgrad- und Verlustleistungsberechnung
- Nachweis der Wellen nach DIN 743
- Festigkeitsnachweis der Verzahnung
- Dokumentation des gesamten Entwicklungsprozesses

## Projektdaten

| Parameter | Wert |
|------------|------------|
| Walzendurchmesser | 1000 mm |
| Walzenbreite | 1500 mm |
| Walzspalt | 0–50 mm |
| Motordrehzahl | 1500 min⁻¹ |
| Walzenumfangsgeschwindigkeit | 0,5 m/s |
| Nennleistung pro Walze | 171 kW |
